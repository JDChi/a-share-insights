# Agent 与 AKShare 本机验证

日期：2026-10-22。新接口：`POST /api/v1/reports/{report_id}/agent/ask`。

## 环境与实现边界

- Python 3.12、AKShare 1.19.1、LlamaIndex core 0.14.25、openai-like 0.8.1。
- 本地配置模型为 MiniMax-M3.1-Flash，经 OpenAI 兼容接口调用 ReActAgent，不依赖原生function calling。
- 单一提示词建议先RAG、证据不足再补查。代码不根据RAG状态自动调用API；测试专门验证模型先调用API时程序不会偷偷补一个RAG调用。
- 原RAG解析、切块、索引和20题不改；原Hit@5基线仍为15/20，本轮Agent成绩不能代替原RAG召回率。
- 金额展示由工具提供，API来源回答逐个校验明确金额与单位；近似展示允许按显示精度四舍五入，元/万元/亿元差异不能忽略。
